# Подключение своего канала

1. В Telegram откройте создание нового сообщения и выберите **Создать канал**. Для первого запуска удобно выбрать частный канал; позже его можно сделать публичным.
2. Задайте название и описание. Подписчиков пока добавлять не требуется.
3. Откройте официальный [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя и уникальное имя бота. Сохраните выданный токен у себя: он дает управление ботом. В чат с помощником токен не пересылайте.
4. В канале откройте **Управление / Изменить → Администраторы → Добавить администратора**, найдите нового бота и включите право **Публиковать сообщения**. Для будущих исправлений пригодится право редактировать сообщения.
5. Напишите в канале одно тестовое сообщение. Оно позволит получить числовой ID частного канала через обновления бота после подключения.
6. Укажите имя бота без `@` в `bot_username` файла `config.json`. Сохраните токен через `powershell -NoProfile -File .\scripts\store_token.ps1`: запрос скрывает ввод, а файл шифруется DPAPI для текущего пользователя Windows и исключён из Git.
7. Выполните `python -m ainews discover-channel`, затем `python -m ainews check-channel`. Эти команды не публикуют сообщения. Если найдено несколько каналов, выберите нужный ID в локальной конфигурации.

Не запускайте `scripts/read_token.ps1` вручную: этот внутренний помощник выводит расшифрованный токен для приложения. Само приложение перехватывает его вывод и не пишет токен в журнал.

Создание бота описано в официальной документации: https://core.telegram.org/bots/tutorial
